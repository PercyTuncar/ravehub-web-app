# ====================================
# INSTRUCCIONES DE CONFIGURACIÓN
# ====================================
#
# 🚨 IMPORTANTE: Frankfurter (proveedor sin API key) NO soporta monedas LATAM
# - ❌ NO soporta: PEN, CLP, COP, ARS, PYG, UYU
# - ✅ Solo soporta: BRL, MXN de LATAM
#
# ⚠️ ACCIÓN REQUERIDA: Configura AL MENOS una de estas APIs:
#   - Open Exchange Rates (RECOMENDADA) ⭐
#   - ExchangeRate-API
#   - CurrencyFreaks
#
# Sin estas APIs configuradas, las conversiones de PEN, CLP, COP, ARS no funcionarán.
#
# Pasos para configurar (5 minutos):
# 1. Registrarte en Open Exchange Rates: https://openexchangerates.org/signup/free
# 2. Copiar tu App ID
# 3. Crear archivo .env.local en la raíz del proyecto
# 4. Agregar: NEXT_OPENEXCHANGE_APP_ID=tu_app_id_aqui
# 5. Reiniciar el servidor: Ctrl+C y luego npm run dev
# 6. Limpiar cache: localStorage.removeItem('ravehub_exchange_rates')
#
# Monedas Soportadas (con APIs configuradas):
# - USD, EUR, MXN, BRL, CLP, COP, ARS, PEN, PYG, UYU
#
# Cache:
# - Geolocalización: 24 horas
# - Tasas de cambio: 1 hora
#
# Para más información, ver: SOLUCION_RAPIDA.md o CURRENCY_API_SETUP.md
